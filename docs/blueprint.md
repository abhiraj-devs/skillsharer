# **App Name**: StudentHub

## Core Features:

- Service Posting: Allow students to post skill-based micro-services they offer.
- Skill Exchange: Enable students to propose and accept trades of services for mutual benefit.
- User Profiles: Showcase student profiles with skills, completed tasks, reviews, and an optional AI-powered portfolio generator tool, which incorporates reviews into the profile display when relevant.
- Request Board: Provide a space for students to post requests for help on small tasks.
- Chat System: Implement a messaging system for direct communication about project requirements.
- Dashboard: Allow students to track their ongoing tasks, earnings, and performance metrics.

## Style Guidelines:

- Primary color: Soft blue (#89B4FA) to convey trust and reliability.
- Background color: Light gray (#F0F4F8) to provide a clean, distraction-free interface.
- Accent color: Warm yellow (#FFD369) for calls to action and highlighting important information.
- Font pairing: 'Space Grotesk' (sans-serif) for headlines and 'Inter' (sans-serif) for body text.
- Use flat, outlined icons with rounded corners for a friendly and approachable feel.
- Employ a card-based layout for service listings and user profiles to enhance scannability and organization.
- Use subtle transition animations and micro-interactions to provide feedback and guide users through the app.
